## 🚀 Some Things I've Built

### [Role-Duty](https://github.com/sadekhosravi/Role-Duty)

An **agentic RAG system for role and responsibility documents**.

It combines:

* LangGraph-based agent orchestration
* Agentic RAG
* Chunkless / structure-aware retrieval
* BM25 + vector search with RRF
* Graph RAG with LightRAG
* MCP-based actions
* Verification and citation grounding
* FastAPI

The interesting part isn't just retrieval — it's designing the system so different agents have different responsibilities, tools and security boundaries.

---

## 🧩 How I Think About AI Engineering

I’m less interested in building a demo that works once and more interested in questions like:

> **How do we make this system reliable?**

How should agents communicate?

Where should state live?

What happens when retrieval fails?

How do we evaluate an agent instead of just looking at a few examples?

How do we control tool access?

How do we keep latency and cost reasonable?

How do we observe what the system is actually doing?

Those are the problems I find most interesting.
